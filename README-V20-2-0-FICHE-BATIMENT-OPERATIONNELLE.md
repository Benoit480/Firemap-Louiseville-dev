# FireMap V20.2.0 — Fiche Bâtiment opérationnelle

Cette version part directement de la V20.1.5 validée.

## Nouveautés
- Bouton `🚨 Vue intervention` dans chaque fiche Bâtiment.
- Vue opérationnelle en lecture rapide avec :
  - adresse et nom du bâtiment;
  - risques confirmés en rouge;
  - accès, FDC, électricité, gaz et matières dangereuses;
  - occupation maximale;
  - photos critiques;
  - score de préparation;
  - contenu complet de prévention.
- Boutons rapides :
  - Carte;
  - Naviguer;
  - Modifier la fiche.
- Bouton pour réduire ou ouvrir les sections du long formulaire.
- L'ancien préplan demeure accessible dans `Anciennes données`.

## Sécurité
- Aucun changement aux règles Firebase.
- Aucun changement aux collections.
- Aucun changement aux bornes, GPS, SMS, véhicules ou navigation.
- Toutes les anciennes données sont conservées.

## Installation
1. Remplacer les fichiers du dépôt GitHub de développement.
2. Faire `Ctrl + F5` sur PC.
3. Fermer complètement la PWA sur iPhone puis la rouvrir.
4. Tester d'abord dans le dépôt de développement.
