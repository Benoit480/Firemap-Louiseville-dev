Chaque compte d’unité est lié à son véhicule et voit directement son profil.
Le compte 102 est le compte Chef, voit toutes les unités et possède seul l’accès au Centre de commandement.
Le compte actif reste mémorisé sur l’appareil et peut être changé avec le badge du haut.

Aucune nouvelle règle Firebase.
