# FireMap V20.2.3 — Verrouillage automatique en intervention

Lorsqu'un appel/intervention est actif :
- la fiche Bâtiment passe automatiquement en lecture seule;
- tous les champs, listes et cases sont désactivés;
- les boutons caméra/import/suppression disparaissent;
- le bouton Enregistrer disparaît;
- un bandeau rouge affiche `MODE INTERVENTION — Consultation seulement`;
- les photos, plans et renseignements restent consultables.

Quand l'intervention se termine, la fiche redevient modifiable automatiquement.

Aucun changement aux règles Firebase n'est nécessaire.
