# FireMap V21.0.4 — Fiche camion intégrée au profil de l’unité

## Modifications
- Suppression de la section séparée « Fiches d’utilisation des véhicules ».
- Chaque profil d’unité affiche directement :
  - état opérationnel;
  - événement lié;
  - nombre de pompiers;
  - type d’alimentation;
  - nombre de sorties actives;
  - détail des sorties, PSI, secteur et affectation;
  - résiduel initial et final;
  - notes;
  - dernière mise à jour.
- Bouton `Créer la fiche` lorsqu’aucune fiche n’existe.
- Bouton `Modifier la fiche` lorsqu’une fiche existe.
- La fiche complète existante est conservée.
- Mise à jour immédiate du profil après enregistrement.
- Aucune nouvelle règle Firebase.
