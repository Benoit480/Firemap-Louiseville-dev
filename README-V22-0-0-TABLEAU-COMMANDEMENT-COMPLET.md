# FireMap V22.0.0 — Tableau de commandement complet

## Ajouts
- Nouveau compteur `Résiduel minimum`.
- Calcul automatique à partir des pressions résiduelles initiales et finales des véhicules.
- Nouvel onglet `Secteurs`.
- Regroupement automatique des sorties actives par secteurs 1 à 5.
- Pour chaque secteur :
  - nombre de véhicules;
  - nombre de sorties;
  - pression moyenne;
  - détail des véhicules, sorties et affectations.
- Compteur du nombre de secteurs actifs.
- Aucun changement aux règles Firebase.

Cette version constitue la première phase de FireMap V22.
