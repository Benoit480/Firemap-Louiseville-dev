# FireMap V20.2.1 — Nouveau bâtiment vers Prévention

Cette version part de la V20.2.0.

## Nouveau fonctionnement
1. Touchez `Ajouter un bâtiment`.
2. Remplissez uniquement :
   - nom;
   - catégorie;
   - adresse;
   - coordonnées GPS;
   - niveau de risque;
   - étages;
   - sous-sol.
3. Touchez `Continuer vers la fiche Prévention`.
4. FireMap crée le bâtiment, puis ouvre automatiquement sa fiche Prévention complète.

Les anciennes sections du formulaire sont masquées seulement lors de la création.
Pour un bâtiment existant, le bouton `Modifier` conserve l’ancien formulaire complet comme sécurité.

## Données
- Aucun changement aux collections Firebase.
- Aucun changement aux règles Firebase.
- Aucun changement aux bornes, GPS, SMS, navigation ou véhicules.
