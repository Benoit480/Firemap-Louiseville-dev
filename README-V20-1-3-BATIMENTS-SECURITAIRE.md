# FireMap V20.1.3 — Bâtiments sécuritaire

Cette version part directement de la V20.1.2 stable.

## Modifications
- Le libellé « Préplans » devient « Bâtiments ».
- Les titres visibles parlent maintenant de fiche bâtiment.
- Aucun identifiant HTML n'a été supprimé ou renommé.
- Aucun fichier JavaScript fonctionnel n'a été modifié.
- L'ancien préplan et le mode prévention restent entièrement actifs en arrière-plan.
- Le cache PWA est renouvelé.

Cette étape est volontairement limitée afin de garantir que la carte et tous les boutons continuent de fonctionner.
